# OSSLibraries Docs

Developer documentation for [OSSLibraries](https://github.com/composable-tu/osslibraries) and its [Hvigor plugin](https://github.com/composable-tu/osslibraries-hvigor-plugin), built with [VitePress](https://vitepress.dev).

Documentation is provided in English (default) and Simplified Chinese.

## Local development

```zsh
pnpm install
pnpm dev
```

## Build

```zsh
pnpm build
```

The static site is emitted to `.vitepress/dist`.

## Structure

- English guides live at the repository root under `guide/`.
- Chinese guides live under `zh/guide/`.
- Site configuration: `.vitepress/config.mts`.
